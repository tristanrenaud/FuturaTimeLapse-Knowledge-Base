# Contributing

This is a community knowledge base for photographers aligning still images into time lapses. Everyone can contribute.

## Ways to help

- **Share a case**: open an issue using the "Share an alignment case" template.
- **Fix or extend docs**: edit files in `docs/` and open a pull request.
- **Ask a question**: open an issue with the "Question" label.

## Writing a case

Include: subject, camera/lens, interval, number of images, what moved (wind, bumped tripod, handheld…), method used (Shift only / Straight / Perspective), alignment area/mask settings, result, and before/after images or clips if possible.

## Share a before and after case

Open an issue using the alignment case template, or add an entry to the [gallery](docs/before-after-gallery.md) in a pull request. You can attach videos to an issue by dragging them into the text box, then use the resulting links in the gallery. A side-by-side video or separate before and after clips both work.

Describe the alignment challenge and settings, credit the creator, and mention any other processing that affects the comparison. Share only media you own or have permission to publish.

## Guidelines

- Be concrete and reproducible; say which app version you used.
- Only share images you own or have permission to share.
- Keep a respectful tone; this is an unofficial community resource.
