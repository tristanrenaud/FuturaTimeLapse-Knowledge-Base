# Before and after gallery

Real time-lapse sequences showing how image alignment changes the result. Each case describes the problem, the approach used and any limitations.

The gallery is just getting started. Have a sequence to share? [Submit an alignment case](../CONTRIBUTING.md#share-a-before-and-after-case).

## Case template

Copy this template when adding a case. Include what you know; do not invent missing details.

```markdown
### Case title

**Subject:** 
**Alignment challenge:** 
**App version and edition:** 
**Alignment method:** 
**Alignment area and mask:** 
**Result and limitations:** 

**Before:** [Watch the unaligned sequence](URL)

**After:** [Watch the aligned sequence](URL)

**Sequence details:** Camera, lens, interval and number of images, if known.
**Credit:** Creator's name or preferred attribution.
```

If a single video shows both versions, link to it instead of providing two separate links. Use comparable framing and playback settings when possible, and note any other processing that affects the comparison.
