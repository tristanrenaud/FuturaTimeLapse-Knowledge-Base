# FuturaTimeLapse-Knowledge-Base

Community knowledge base to help photographers **align still images** when building time lapses: wind shake, bumped tripods, re-mounted or handheld cameras, drift, and flicker. Built around [Futura Time Lapse](https://camerafutura.com/futura-time-lapse), but the principles apply broadly. Unofficial, community-driven.
